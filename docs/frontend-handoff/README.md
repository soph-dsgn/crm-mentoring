# Интеграция frontend с сервером

Рабочее пространство React использует FastAPI для групп, профилей, стратегий, задач, согласований, встреч, ДЗ и Knowledge. Владелец управляет аккаунтами и миграцией. Старые копии браузера изолированы от рабочего пространства. В релизной ветке добавлены перенос ученицы, перемещение задач и удаление пустых разделов.

Актуальные источники: [API-контракт](../architecture/api-contract.md), [чеклист приёмки](../release/FINAL_ACCEPTANCE.md), [развёртывание](../deployment/README.md). Документы этапов ниже сохраняют историю интеграции и могут описывать устаревшие пробелы и маршруты.
