# Исходные материалы миграции

Каталог содержит исторические стратегии, имена, исходные тексты и ссылки. Доступ к материалам ограничьте владельцем и оператором, которому владелец поручил перенос. Передавайте отдельные PDF только уполномоченному получателю по согласованному защищённому каналу.

`strategies/` содержит исходные PDF и результат их разбора. Для актуального переноса используйте свежую копию AppData с пользовательскими правками. `knowledge-seed.json` можно использовать как явно выбранный исходный файл KnowledgeData v1, если владелец проверил его содержимое и подтвердил перенос.

Сборка frontend использует контекст `frontend/`. Пути исторических публикаций должны возвращать 404. В старых Git-коммитах и снимке репозитория историческое содержимое может оставаться доступным пользователям с доступом к репозиторию. Владелец отдельно проверяет доступ к Git, старым артефактам сборки, CDN и прежним публикациям.
