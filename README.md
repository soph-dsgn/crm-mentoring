# Кураторская

CRM для владельца и кураторов. React обслуживает рабочее место, FastAPI проверяет права и записывает данные в PostgreSQL. Существующий кабинет ученицы доступен через её персональный аккаунт. Куратор может зафиксировать сдачу и доработку самостоятельно.

Группа → профиль → стратегия → задачи → черновик ДЗ → выдача → сдача → проверка. Принятая работа обновляет прогресс связанных задач. Согласования с Аней ведутся отдельно.

## Локальный запуск на Windows

В корне репозитория, при запущенном Docker Desktop:

```powershell
.\deploy\start-acceptance.ps1
docker compose -f deploy/compose.acceptance.yml run --rm backend python -m app.cli.bootstrap_owner --login acceptance.owner --confirm-database acceptance --confirm-first-owner
```

Откройте [Кураторскую](https://localhost:8443). Сертификат сгенерирован для тестового localhost. Войдите с одноразовым паролем и задайте новый. После сохранения сразу откроется рабочее место. Создайте синтетические аккаунты в разделе «Аккаунты». Подробности, тестовые сценарии и остановка окружения описаны в [чеклисте приёмки](docs/release/FINAL_ACCEPTANCE.md).

## Данные и развёртывание

- «Миграция» загружает проверенный владельцем файл AppData. В «Промптах» владелец может активировать пустую библиотеку или перенести KnowledgeData v1. Импорт обоих форматов требует отдельного подтверждения
- Прежние копии в браузере остаются доступны владельцу для выгрузки. Исходные PDF и seed-файлы находятся в [закрытых материалах миграции](migration-sources/README.md)
- Установка и обновление на сервере описаны в [пакете для оператора](docs/deployment/README.md). Полное восстановление выполняется из архива PostgreSQL
