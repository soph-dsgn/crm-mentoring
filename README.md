# Кураторская

Локальное рабочее приложение куратора на React, TypeScript и Vite. Шрифт Manrope; существующая визуальная система и токены находятся в `frontend/src/vision-ui.css`.

Параметры движения собраны в `frontend/src/motion.ts` и применяются через Framer Motion: переходы между рабочими экранами, диалоги, списки, разделы стратегии и индикаторы вкладок. Для системной настройки уменьшения движения смещения отключаются, а переходы становятся короче.

## Структура

- `frontend/` — React-приложение, публичные материалы и скрипты импорта
- `backend/` — FastAPI-приложение, миграции и backend-тесты
- `docs/` — архитектурная документация, UX-аудит и визуальные артефакты

## Запуск

```bash
cd frontend
npm install
npm run dev
npm run build
```

## Данные стратегий

`frontend/public/strategies` содержит 19 исходных PDF четырёх групп. `frontend/scripts/import-strategies.py` извлекает их в `frontend/public/strategies/strategy-seed.json`: 4 группы, 19 учениц, 90 разделов, 749 задач. Каждая задача сохраняет исходный файл, название, статус, комментарии, период и найденные материалы. Исходный PDF доступен из стратегии ученицы. Некоторые разрывы строк в исходном PDF остаются видны в извлечённом тексте; два продолжения строк без названия задачи сохранены в заметках соответствующих учениц.

При первом открытии новой версии приложение создаёт локальные копии прежних данных (`crm-mentoring-v1-before-strategies-import` и `crm-mentoring-v1-before-section-strategies-v1`), убирает демонстрационные записи из рабочего интерфейса и добавляет реальные записи. Совпадения по имени и группе не перезаписываются: их список доступен в окне «Данные и резервные копии». Повторный импорт при перезагрузке не выполняется. Из этого окна можно скачать текущие данные и обе сохранённые копии. Если профиль уже импортирован с тем же идентификатором, приложение добавляет только отсутствующие разделы и задачи, сохраняя правки существующих записей.

Даты групп: 03.08.2026–18.01.2027, 07.09.2026–07.03.2027, 17.09.2026–17.03.2027, 01.10.2026–01.04.2027. Для расчёта используется календарное прибавление месяцев; половина месяца соответствует 15 дням. Статус группы меняется только вручную и не завершает персональные стратегии.

## Рабочий сценарий

Группа → ученица → стратегия с раскрывающимися смысловыми разделами → выбор задач → черновик ДЗ → редактирование и копирование → история ДЗ и проверка. Четыре статуса стратегии: «Не начато», «В процессе», «На паузе», «Выполнено». Период из PDF хранится отдельно от необязательного дедлайна и не создаёт просрочку. Выдача ДЗ не завершает задачу; принятие работы обновляет связанную стратегию. Задачи Ани имеют отдельные статусы согласования.

## Хранение

Данные хранятся в `localStorage` текущего браузера. Для повседневной работы с реальными данными необходимы серверная синхронизация, контроль доступа и регулярные резервные копии. Пока они не реализованы, регулярно скачивайте JSON через «Данные и резервные копии».

Промпты и учебник используют отдельный встроенный импорт из DOCX; их работа описана в `frontend/scripts/build-knowledge-seed.mjs`.
