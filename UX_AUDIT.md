# UX-аудит «кураторской»

Проверены маршруты «обзор → группа → ученица → стратегия → домашка → проверка», согласования с Аней, формы, поиск, знания и состояния без данных. Изменения касаются представления и навигации; модели данных и правила расчёта прогресса сохранены.

| Серьёзность | Экран | Проблема и причина | Решение |
| --- | --- | --- | --- |
| Высокая | Создание группы | Новая группа попадала в бэклог, а список оставался на вкладке «Активные»: результат создания был невидим | После сохранения открывается группа; выбранный фильтр сохраняется |
| Высокая | Создание ученицы | После сохранения нужно было снова искать созданную запись | Открывается её рабочий профиль |
| Высокая | Задача | Просмотр выводил свойства подряд, смена статуса требовала второго окна с полной формой | Отдельная иерархия: контекст, описание, состояние, материалы, подробности; статус меняется в просмотре |
| Высокая | Проверка связанной задачи | Блокировка статуса сообщала о проверке, но не вела к самой работе | Из задачи можно сразу открыть связанную домашку и принять работу или вернуть её на доработку |
| Высокая | Домашние задания | Поля выполненной работы и комментария показывались для любого статуса; решение по проверке терялось | Поля и действия зависят от состояния ДЗ; содержание раскрывается отдельно |
| Высокая | Задачи Ани | Карточка одновременно показывала тип, срок, ссылку как текст и как форму; действие терялось среди полей | Сначала статус, материал, комментарий и следующий шаг; редактируемые детали раскрываются по запросу |
| Средняя | Глобальная навигация | Иконки требовали запоминания, а переключатель показывал старую группу в общих разделах | Подписаны пункты навигации; переключатель отражает текущий контекст |
| Средняя | Группы и стратегии | Жизненный цикл групп и общий список учениц были слиты на одном длинном экране | Два представления внутри раздела; фильтры и вид сохраняются при возврате |
| Средняя | Поиск | Одинаковые имена учениц было трудно различать | В результатах показаны группа и тип записи |
| Средняя | Формы | Все поля задачи и профиля показывались сразу, включая редко нужные | Основные поля видны сразу, остальные сгруппированы в раскрывающихся секциях |
| Средняя | Модальные окна | Закрытие по Escape и возврат фокуса работали непоследовательно | Общий механизм фокуса, Tab и Escape для всех существующих окон |
| Средняя | Переход из общей очереди | После открытия задачи или ДЗ терялся путь обратно к исходной очереди | В профиле есть явный возврат к исходному разделу или списку учениц |
| Низкая | Пустые стратегии | «0%» выглядело как отсутствие прогресса, хотя плана ещё нет | Показано «—» или «Стратегии пока пусты» |

Проверены существующие пустые, загрузочные и ошибочные состояния в коде. База знаний уже имеет загрузку и ошибку импорта; сохранение CRM показывает глобальную ошибку при нехватке места. Успех основных действий отражается переходом к созданной записи или сменой её состояния. Данные остаются в существующем хранилище браузера.

Проверка: TypeScript и production-сборка проходят; сценарный скрипт проверяет миграцию, прогресс, домашние задания, согласования и серверный рендер ключевых экранов. Dev-сервер отвечает HTTP 200. Интерактивная проверка desktop/mobile в браузере не проведена: доступ к локальной вкладке через инструмент управления браузером в этой сессии заблокирован.
